# GameDev Toolbox - Downloads

GameDev Toolbox keeps a game's ideas, artwork and reference pictures in one shared place, so everyone helping with the game can add to it and see what's been decided.

## Download

Go to **[Releases](../../releases/latest)** and download `GameDev_Toolbox_Setup_<version>.exe`, then double-click it.

- No administrator rights are needed.
- Windows may say *"Windows protected your PC"* because the program is new: click **More info**, then **Run anyway**.
- Once installed, the toolbox updates itself: it checks here when it starts and offers each new version.

Every release also has a `.sha256` file: the installer's fingerprint, which the built-in updater checks before installing.

## Joining a game's library

You'll need **Git for Windows** (https://git-scm.com/download/win, default options) and an invitation to the game's library on GitHub (check your email). Then, in the toolbox, choose **Join a shared library** and paste the address you were given.
